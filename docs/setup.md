# Preparación

## Requisitos

- Python 3.11+
- Git
- Repositorio con acceso de escritura

## Ejecución

```bash
python scripts/validate_sample.py
python -m unittest discover -s tests
```

## Seguridad

No copies exportaciones reales en `samples/`. Mantén cualquier dato personal fuera del repositorio y usa secretos administrados para futuras credenciales.
